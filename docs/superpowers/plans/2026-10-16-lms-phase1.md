# runly.lms Phase 1 (core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `runly.lms` phase 1: courses/sections/lessons authoring, internal learners, enrollments with due dates, progress with video resume and sequential unlock, learner home and full-screen player.

**Architecture:** Official core module following the `runly.attendance` pattern: Prisma models `lms_*` + forward migration, Hono router in `apps/api/src/routes/lms/` (thin routes, service factory, pure rules file), SDK domain `packages/sdk/src/domains/lms.js`, desktop screens in `apps/desktop/src/modules/runly.lms/`. Spec: `docs/superpowers/specs/2026-10-16-lms-design.md`.

**Tech Stack:** Prisma 7, Hono, Node test runner, React + TanStack Query + `@runly/ui`, Supabase Storage signed uploads.

## API contract (shared by both workstreams — do not deviate)

All responses `{ data }`; errors `{ error, code? }` with HTTP status. Ids are UUID v7 strings. Dates ISO strings.

Serialized course: `{ id, title, summary, description, coverFileId, coverUrl, category, level, status, visibility, sequential, selfEnroll, estimatedMinutes, sectionCount, lessonCount, enrollmentCount, createdAt, updatedAt }`.
Serialized section: `{ id, courseId, title, position, lessons: Lesson[] }`.
Serialized lesson (authoring): `{ id, courseId, sectionId, title, kind, body, fileId, fileName, embedUrl, durationSeconds, position, required, enabled }`.
Serialized enrollment: `{ id, courseId, learnerId, learner: { id, displayName, email, userProfileId }, status, source, dueAt, overdue, startedAt, completedAt, progressPct, lastLessonId, createdAt }`.

| Method | Path | Permission | Body / query | Returns |
|---|---|---|---|---|
| GET | `/lms/catalog` | lms.access | — | published self-enroll courses `Course & { enrollment: Enrollment\|null }` |
| GET | `/lms/my/courses` | lms.access | — | `{ active: Item[], completed: Item[] }`, Item = `{ course, enrollment }` |
| POST | `/lms/courses/:id/enroll` | lms.access | — | Enrollment (201); 409 if not published or not selfEnroll |
| GET | `/lms/learn/:courseId` | lms.access | — | `{ course, enrollment, sections: [{ id, title, lessons: [{ id, title, kind, durationSeconds, required, status: 'locked'\|'available'\|'in_progress'\|'completed', positionSeconds }] }] }`; 403 if not enrolled (managers get a preview with enrollment null and nothing locked) |
| GET | `/lms/learn/lessons/:lessonId` | lms.access | — | `{ lesson: { id, title, kind, body, embedUrl, durationSeconds, mediaUrl, fileName }, progress: { status, positionSeconds }, prevLessonId, nextLessonId }`; 409 `LOCKED` |
| POST | `/lms/learn/lessons/:lessonId/progress` | lms.access | `{ positionSeconds?, durationSeconds?, completed? }` | `{ lessonStatus, enrollment }` |
| GET | `/lms/courses` | lms.course.manage | `?status=` | Course[] |
| POST | `/lms/courses` | lms.course.manage | course fields | Course (201) |
| GET | `/lms/courses/:id` | lms.course.manage | — | `{ course, sections: Section[] }` |
| PATCH | `/lms/courses/:id` | lms.course.manage | partial course fields incl. `status` | Course; publishing requires >= 1 enabled lesson (409 `EMPTY_COURSE`) |
| DELETE | `/lms/courses/:id` | lms.course.manage | — | Course with status `archived` |
| POST | `/lms/courses/:id/sections` | lms.course.manage | `{ title }` | Section (201) |
| PATCH / DELETE | `/lms/sections/:id` | lms.course.manage | `{ title }` | Section / `{ id }` (delete cascades lessons) |
| POST | `/lms/sections/:id/lessons` | lms.course.manage | lesson fields | Lesson (201) |
| PATCH / DELETE | `/lms/lessons/:id` | lms.course.manage | partial lesson fields (incl. `sectionId`) | Lesson / `{ id }` (delete = `enabled:false`) |
| POST | `/lms/courses/:id/reorder` | lms.course.manage | `{ sections: [{ id, lessonIds: [] }] }` | `{ sections: Section[] }` |
| POST | `/lms/media/presign` | lms.course.manage | `{ fileName, mimeType, sizeBytes }` | `{ fileId, uploadUrl, token }` |
| POST | `/lms/media/:fileId/confirm` | lms.course.manage | — | `{ fileId, fileName }` |
| GET | `/lms/courses/:id/enrollments` | lms.enrollment.manage | — | Enrollment[] |
| POST | `/lms/courses/:id/enrollments` | lms.enrollment.manage | `{ userProfileIds: [], dueAt? }` | `{ created, reactivated, skipped }` |
| PATCH | `/lms/enrollments/:id` | lms.enrollment.manage | `{ dueAt?, status?: 'active'\|'dropped' }` | Enrollment |

SDK `runly.lms` (every method takes `token` last): `getCatalog`, `getMyCourses`, `enroll(courseId)`, `getOutline(courseId)`, `openLesson(lessonId)`, `saveProgress(lessonId, data)`, `listCourses(query)`, `createCourse(data)`, `getCourse(id)`, `updateCourse(id, data)`, `archiveCourse(id)`, `createSection(courseId, data)`, `updateSection(id, data)`, `deleteSection(id)`, `createLesson(sectionId, data)`, `updateLesson(id, data)`, `deleteLesson(id)`, `reorder(courseId, data)`, `presignVideo(data)`, `confirmVideo(fileId)`, `listEnrollments(courseId)`, `assign(courseId, data)`, `updateEnrollment(id, data)`.

### Task A2: Pure rules (TDD)
`apps/api/src/routes/lms/lms-core.js` exports:
```js
export class LmsError extends Error { constructor(message, status = 400, code = null) { super(message); this.status = status; this.code = code } }
export const LESSON_KINDS = ['video', 'embed', 'text', 'file']
export const LEVELS = ['basic', 'intermediate', 'advanced']
export const COURSE_STATUSES = ['draft', 'published', 'archived']
export const AUTO_COMPLETE_RATIO = 0.9
export const VIDEO_MAX_BYTES = 50 * 1024 * 1024
// lessons: ordered array [{ id, required, enabled }]; completedIds: Set
export function progressPct(lessons, completedIds) // integer 0..100 over required+enabled
export function lessonStates(lessons, progressById, { sequential, locked = true }) // Map id -> 'locked'|'available'|'in_progress'|'completed'; sequential: locked if any earlier required lesson not completed
export function shouldAutoComplete({ kind, positionSeconds, durationSeconds }) // video|embed with duration > 0 and position >= 90%
export function isOverdue(enrollment, now = new Date()) // status active && dueAt && dueAt < now
export function normalizeEmbedUrl(raw) // https only; youtube watch/short/youtu.be -> https://www.youtube-nocookie.com/embed/<id>; vimeo.com/<id> -> https://player.vimeo.com/video/<id>; other https kept; else throws LmsError 400
export function normalizeCourseInput(body, { partial }) // trims, validates title (1..200), level, status, estimatedMinutes >= 0 int, booleans; returns prisma data
export function normalizeLessonInput(body, { partial }) // title, kind, body, fileId, embedUrl (normalized), durationSeconds, required, sectionId
export function orderLessons(sections) // flatten sections sorted by position, lessons sorted by position, enabled only
```

### Task A3: Services, media, router, wiring
- [ ] `lms-service.js` (authoring + enrollments). Learner resolution: `ensureLearnerForProfile(companyId, userProfileId)` upserts `LmsLearner` with displayName/email from `UserProfile` (reject profiles with `isBot`/`is_bot` true — check the actual UserProfile field name in schema). Course delete -> status `archived`. Publishing with zero enabled lessons -> `LmsError('Agrega al menos una lección antes de publicar.', 409, 'EMPTY_COURSE')`. New sections/lessons get `position = max + 1`. Reorder validates every id belongs to the course, rewrites positions and `sectionId` in a `$transaction`. Assign: for each profile ensure learner, create enrollment (`source: 'assigned'`, `assignedById`, `dueAt`) or reactivate a dropped one; skip existing active/completed. Course serializer counts via `_count`, `coverUrl` via `signFile(coverFileId, 'card')`; lesson `fileName` from FileAsset `originalName`. Every query filters `companyId`.
- [ ] `lms-learn-service.js`. Catalog: published + selfEnroll + enabled. Enroll: published+selfEnroll else 409. Outline: requires active/completed enrollment for the current profile, else 403 unless `canManage` (preview). Progress: upsert, `maxPositionSeconds = max(old, position)`, store `durationSeconds` on the lesson when it was null and client sent one, complete when `completed === true` or `shouldAutoComplete`; then recompute `progressPct` from all progress rows; when 100 and not completed -> `status: 'completed', completedAt: now`.
