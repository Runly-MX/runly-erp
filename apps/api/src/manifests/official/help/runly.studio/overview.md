# Runly Studio

Crea un diseño en blanco o elige una de las tres plantillas originales.
Añade texto, rectángulos, círculos e imágenes PNG, JPG o WebP mediante el panel izquierdo.
Selecciona un elemento para modificar su texto, posición, color o rotación en Propiedades.
Los tiradores permiten escalar y rotar con el puntero.

Pulsa **Guardar** antes de volver a Mis diseños. Al reabrir se conservan los elementos editables.
**Exportar PNG** descarga la página completa a su tamaño original, independientemente del zoom.
Las imágenes se conservan como archivos originales privados en Archivos; se necesitan sus permisos de subida y lectura.

Esta primera versión muestra únicamente tus diseños dentro de la empresa activa.
Si otra pestaña guardó una revisión más reciente, Studio conserva tus cambios en pantalla y rechaza la sobrescritura.
El catálogo empresarial, el historial y la colaboración se incorporarán en las siguientes entregas.
