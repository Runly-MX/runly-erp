title: Reservas
summary: Reservaciones de mesas por horario, con la capacidad de cada mesa y la llegada del cliente.
---
Reservas es la agenda de mesas del dia. Funciona con el sistema de Reservaciones: se activa por sucursal en **Administracion > Reservas** (primero se revisa, sin cambiar nada, que las reservas vigentes quepan).

- **Nueva reserva**: cliente, telefono, fecha y hora, personas, duracion y mesa. Puedes dejar que el sistema elija la mejor mesa libre para ese numero de personas.
- Una mesa puede tener varias reservas el mismo dia mientras no se encimen (se cuenta un margen para limpiarla). La mesa no queda «Reservada» todo el dia: en el comandero se ve libre y con la hora de su proxima reserva.
- Una mesa ocupada ahora no acepta una reserva que empiece antes de que pueda desocuparse, y no se puede sentar a clientes sin reserva en una mesa reservada para la siguiente rotacion.
- **Llego** abre la cuenta de la mesa y te lleva a ella. Tambien puedes **cambiar hora o mesa**, marcar **No llego** (cuando ya paso la hora) o **cancelar** (la mesa queda libre en ese horario).
- Las reservas hechas en linea desde la pagina de reservaciones o el sitio web aparecen aqui, y las de POS ocupan esos horarios en linea.
- Cada reserva aparece en el Calendario del sistema de reservaciones.
