---
Todas las plantillas estan en una sola lista, con la columna de origen (que modulo y tipo). Al crear una, elige el modulo y el tipo de documento (resguardo, certificado, empleado, vehiculo, orden de compra, **Documento general**...); solo aparecen los tipos de modulos activos que puedes usar. y sube tu propio archivo de Word, Excel, PowerPoint o PDF, o crea un documento en blanco que ya incluye los campos de ese tipo.

- Al subir o reemplazar un archivo, Runly sugiere las etiquetas automaticamente en Word, Excel y PowerPoint. Tambien puedes usar "Sugerir etiquetas" en un Word para que Runly coloque las etiquetas junto a titulos como "Nombre del empleado".
- En "Campos" confirmas que dato va en cada etiqueta y publicas la plantilla. Puedes probarla con datos de ejemplo, incluso en borrador.
- Una misma plantilla se reutiliza cuantas veces necesites; reemplazar el archivo crea una version nueva y los documentos ya generados no cambian.
- Una plantilla nueva es **Personal**; usa **Compartir con la empresa** para que la use todo el equipo. Para volverla predeterminada de su tipo primero debe estar compartida.
- **Reemplazar archivo** acepta cualquier formato que permita el tipo (por ejemplo, cambiar un Word por un PowerPoint).
- **Documento general** sirve para formatos que no dependen de un registro (un manual, una carta): acepta etiquetas libres, que no estan atadas a los datos de un modulo.
