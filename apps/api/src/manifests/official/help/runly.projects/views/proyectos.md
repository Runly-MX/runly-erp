title: Proyectos
summary: Organiza tareas por proyecto en Kanban, lista, semana o Gantt, y mide la carga de cada persona.
---
Elige un proyecto y organiza sus tareas como prefieras: arrastrando tarjetas en un tablero, en una lista simple, o en una linea de tiempo por fechas.

- Crea un proyecto nuevo desde la barra lateral; cada uno tiene su propio tablero, tareas y estado (activo, pausado, etc.).
- En **Kanban**, arrastra una tarea entre columnas para cambiar su estado; el numero junto a cada columna te dice cuantas tareas tiene.
- **Semana** muestra las tareas de la semana por dia; cambia de semana con las flechas.
- **Gantt**: cada tarea es una barra en el tiempo (escala dia, semana o mes). Arrastrala para moverla o estira sus bordes para cambiar fechas. Une tareas con dependencias ("Esta tarea espera a..." / "Esta tarea bloquea a..."); al mover una tarea, Runly ofrece **Moverlas tambien** para recorrer las que dependen de ella, y no permite dependencias circulares.
- **Carga**: las horas estimadas de cada miembro por semana contra su capacidad semanal (**Horas por semana**, editable por miembro), para ver quien esta saturado.
- **Resumen**: avance del proyecto, tareas por estado y horas registradas contra las estimadas.
- En una tarea, **Estimacion** guarda las horas previstas; registra tiempo a mano con **Registrar** o con el cronometro (si olvidas detenerlo, Runly lo cierra solo despues de un tiempo).
- El detalle de una tarea incluye subtareas, archivos y documentos adjuntos, y un hilo de comentarios para discutir el avance sin salir de la tarea.
- Usa **Crear canal** para abrir un canal de chat vinculado al proyecto cuando el equipo necesite discutir algo en tiempo real.
- Exporta o descarga la informacion del proyecto desde el icono correspondiente en la barra superior, si necesitas compartirla fuera de Runly.
