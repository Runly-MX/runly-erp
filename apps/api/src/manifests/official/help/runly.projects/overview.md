Runly Proyectos organiza el trabajo en proyectos con tareas, que puedes ver como tablero (arrastrando tarjetas entre columnas), como lista, por semana, como Gantt o como carga de trabajo por persona.

- Cada proyecto tiene sus propias columnas (por ejemplo, Backlog, En desarrollo, En revision, QA, Deploy) que puedes ajustar segun como trabaje tu equipo.
- Una tarea puede tener descripcion, prioridad, etiquetas, fecha de inicio/limite, responsable y subtareas.
- **Mis tareas** es tu proyecto personal: tareas propias que no pertenecen a ningun equipo.
- **Estimacion y tiempo**: cada tarea puede tener horas estimadas y registrar el tiempo trabajado, a mano o con el cronometro. La tarea compara las horas registradas contra las estimadas.
- Las tareas pueden repetirse (cada dia, cada semana, cada dos semanas o cada mes) y vincularse con registros de otros modulos, por ejemplo una orden de compra o un contacto; el registro vinculado tambien muestra sus tareas.
- Cada tarea tiene su propio hilo de comentarios y espacio para adjuntar archivos y documentos, para no tener que buscar el contexto en otro lado.
- Un proyecto puede tener su propio canal de chat vinculado, para discutir el trabajo sin salir del contexto del proyecto.

### Con MirAI

Con la pestaña de MirAI abierta puedes pedirle, por ejemplo:

- "Que tareas tengo vencidas"
- "Crea una tarea para Ana en el proyecto Lanzamiento para el viernes"
- "Cuantas tareas lleva completadas cada proyecto"
- "Cambia el estado de esta tarea a Listo"
- "Registra 2 horas en esta tarea"
- "Quien del equipo tiene mas carga esta semana"

Si tienes una tarea o un proyecto abierto, MirAI sabe cual es: puedes pedirle cambios sobre "esta tarea" sin repetir su nombre. Como con cualquier accion, te muestra una tarjeta para confirmar antes de guardar algo; solo puede crear, editar o eliminar tareas en proyectos donde ya eres miembro.

### Alcances y limites

- Cambiar entre vistas (Kanban, Lista, Semana, Gantt, Carga) no cambia los datos, solo como los ves — la misma tarea se ve reflejada igual en cualquier vista.
- Las tareas tambien pueden aparecer en tu Calendario si tienen fecha, para verlas junto con el resto de tu agenda.
